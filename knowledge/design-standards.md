# Design Standards — 플랫폼 무관 S-Tier 체크리스트

> 출처: S-Tier SaaS 디자인 벤치마크 체크리스트 이식 (Stripe / Linear / Airbnb 급 기준).
> 웹·모바일 공통으로 적용되는 **정량 표준 앵커**다. 모바일 전용 규칙은 `standards-mobile.md` 참조.
> 판정자는 이 값들을 스크린샷에서 **측정 가능한 기준**으로 사용한다.

## 색 (Color)

- **Primary**: 브랜드 주색 1개(+ 강조/hover용 명암 변형 1~2단계).
- **Neutral**: 회색 계열 **5~7단계** (배경 → 보더 → 보조텍스트 → 본문텍스트 → 헤딩).
- **Semantic**: 상태 색 4종을 일관되게 사용.
  - 성공 = **green**, 에러 = **red**, 경고 = **amber**, 정보 = **blue**.
  - semantic 색을 장식용으로 오용 금지 (예: 성공 green을 일반 버튼에).
- **다크모드**: 라이트/다크 양쪽 팔레트를 정의하고 대비를 각각 검사.
- **대비 검사 (필수)**: 모든 텍스트/배경 조합을 **WCAG AA 대비 4.5:1** 이상으로 검사.
  - 큰 텍스트(18pt bold 또는 24px+)는 3:1 허용.
  - 미달 조합은 `[Blocker]` 후보.

## 타이포그래피 (Typography)

- **모듈러 스케일**: 크기를 임의값이 아닌 스케일에서 선택.
  - 예: H1 32 / H2 24 / H3 20 / Body 14~16 / Caption 12.
- **제한된 굵기**: weight는 소수(예 400 / 500 / 700)로 제한. 5종 이상 남발 금지.
- **line-height**: 본문 **1.5 ~ 1.7**. 제목은 더 타이트(1.1~1.3) 허용.
- 한 화면에 폰트 패밀리는 1~2종으로 제한.

## 간격 (Spacing)

- **8px 베이스 유닛의 배수**만 사용: **4 / 8 / 12 / 16 / 24 / 32**(4px는 8px의 절반 하위단위로 허용).
- 임의값(예 `13px`, `17px`, `23px`)은 그리드 위반 — 지적 대상.
- 동일 위계 요소 간 간격은 일관되게. 간격 리듬이 곧 시각적 질서다.

## Border Radius

- **소수의 일관값**만 사용한다.
- 입력 필드/버튼: **4 ~ 6px**.
- 카드/모달: **8 ~ 12px**.
- 한 화면에서 radius 값이 3종 이상 섞이면 일관성 저하로 지적.

## 컴포넌트 상태 일관성 (Component States)

인터랙티브 컴포넌트는 아래 5개 상태를 **모두 정의**하고 시각적으로 구분되어야 한다.

- **default** — 기본.
- **hover** — 포인터 오버(웹).
- **active** — 눌림(press).
- **focus** — 키보드 포커스 (명확한 포커스 링).
- **disabled** — 비활성 (저채도 + 커서/피드백 차단).

상태 누락(특히 focus·disabled)은 접근성/견고성 결함이다.

## 마이크로 인터랙션 (Micro-interactions)

- 트랜지션/애니메이션 지속시간: **150 ~ 300ms**.
- 이징: **ease-in-out** (또는 그에 준하는 자연스러운 커브). linear 남용 금지.
- 과도한 지속시간(>500ms)이나 무의미한 바운스는 슬롭 신호 (`anti-slop.md` 참조).

## 요약 앵커 표

| 항목 | 표준값 |
|------|--------|
| 텍스트 대비 | **4.5:1** (큰 텍스트 3:1) |
| 간격 그리드 | **8px** 배수 (4/8/12/16/24/32) |
| line-height (본문) | 1.5 ~ 1.7 |
| radius (입력/버튼) | 4 ~ 6px |
| radius (카드) | 8 ~ 12px |
| 트랜지션 | 150 ~ 300ms, ease-in-out |
| Neutral 단계 | 5 ~ 7 |
