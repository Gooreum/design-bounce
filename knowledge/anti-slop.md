# Anti-Slop — AI 슬롭 금지목록

> 출처: Superdesign anti-slop 규칙 이식.
> "AI 슬롭"은 그럴듯하지만 성의 없고 관성적인, 자기 취향의 메아리로 수렴한 디자인이다.
> 판정자는 아래 패턴을 발견하면 **왜 슬롭인지 + 대안**과 함께 지적한다. 각 항목은 트리아지 등급으로 분류한다.

## 금지 목록

### 1. 이모지를 아이콘/아바타로 사용 금지
- **왜 슬롭인가**: 이모지는 플랫폼마다 렌더가 다르고 플레이스홀더처럼 보여 미완성 인상을 준다. (실물 실패 사례: **PetCycle** — 이모지 아바타로 신뢰도 상실.)
- **대안**: 전용 아이콘 세트(SF Symbols / Material Symbols / 라인 아이콘 팩) 사용, 아바타는 실제 이미지 또는 이니셜 도형.

### 2. 탁한 저채도 팔레트 · 명도대비 부족 금지
- **왜 슬롭인가**: 채도·명도 대비가 낮으면 위계와 초점이 사라져 화면이 흐릿하고 평평해 보인다. 접근성(4.5:1)도 위반한다.
- **대안**: 명확한 명도 단계(밝은 배경 ↔ 진한 텍스트)와 하나의 뚜렷한 강조색으로 초점을 만든다.

### 3. 균일한 카드 나열 금지 ("3-identical-cards row" 안티패턴)
- **왜 슬롭인가**: 똑같은 크기·구조의 카드 3개를 한 줄에 나열하는 것은 AI 기본 출력의 전형으로, 정보 위계 없이 관성적이다.
- **대안**: 콘텐츠 중요도에 따라 크기·레이아웃에 위계를 준다(주 카드 강조 + 보조), 실제 데이터에 맞춘 비대칭 그리드.

### 4. 무의미한 그라디언트 · 보라 그라디언트 · 무지개 금지
- **왜 슬롭인가**: 목적 없는 그라디언트(특히 보라→파랑, 무지개)는 "AI가 만든 티"의 대표 신호이며 콘텐츠를 방해한다.
- **대안**: 단색 또는 매우 미묘한 톤 그라디언트만 목적이 있을 때(깊이·상태 표현) 절제해서 사용.

### 5. 기본 폰트(Inter / Roboto) 무비판 사용 지양
- **왜 슬롭인가**: 아무 근거 없이 Inter/Roboto를 쓰면 브랜드 개성 없는 "디폴트 룩"이 되어 슬롭으로 읽힌다.
- **대안**: 제품 톤에 맞는 폰트를 **구체 레퍼런스와 함께 지목**한다(예: "Linear 느낌의 기하학 산세리프"). 기본 폰트를 쓰더라도 근거를 명시.

## 슬롭 탐지 체크 요약

| 안티패턴 | 신호 | 대안 |
|----------|------|------|
| 이모지 아이콘/아바타 | 📱🐶 를 UI 요소로 | 아이콘 세트 / 실제 이미지·이니셜 |
| 탁한 저채도 | 흐릿·초점 없음, 대비<4.5:1 | 명도 단계 + 강조색 |
| 균일 카드 나열 | 동일 카드 3개 한 줄 | 위계 있는 비대칭 레이아웃 |
| 무의미 그라디언트 | 보라→파랑, 무지개 배경 | 목적 있는 단색/미묘 톤 |
| 디폴트 폰트 남용 | 근거 없는 Inter/Roboto | 레퍼런스 기반 폰트 선정 |
